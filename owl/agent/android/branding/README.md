# Logo OWL

`logo-owl-original.jpg` is the original `logo OWL.jpg` supplied by the owner.
The Android foreground resources preserve its emblem and metallic colors,
cropped without the small wordmark/tagline for readability at launcher size.
Source crop: x=33.5%..66.2%, y=7.3%..68.5%. The crest is fitted inside the
central 66dp safe area of a 108dp adaptive icon (432px resource).
Android 13 themed icons use a monochrome mask derived from the same artwork.
The black icon/splash background matches the original image.
